# 文档索引

Pandora-RAG 的文档按用途分层，当前实验代码仍从仓库根目录运行。

## 当前有效文档

- [`active/experiments.md`](active/experiments.md)：数据、轨迹、特征和实验运行协议。
- [`active/STORAGE_LAYOUT.md`](active/STORAGE_LAYOUT.md)：缓存、模型和结果的存储约定。
- [`active/project_status.md`](active/project_status.md)：当前阶段成果总览。
- [`active/next_steps.md`](active/next_steps.md)：WWW 2027 整理后的后续工作入口。
- [`active/path_manifest.md`](active/path_manifest.md)：本次目录迁移清单。

- [`reports/stage2/`](reports/stage2/)：Probe、特征诊断、消融和基线报告。

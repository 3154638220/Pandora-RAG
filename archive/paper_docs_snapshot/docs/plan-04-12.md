### 3.1 一句话

> E-value 是 Pandora-RAG 的部署安全层——以近乎零额外成本，为自适应停止提供分布无关的在线风险监控，而 Conformal Prediction 在相同场景下既昂贵又脆弱。

### 3.2 E-value 的正确定位


| 维度   | 旧叙事（已废弃）      | 新叙事              |
| ---- | ------------- | ---------------- |
| 核心功能 | 控制错误率 ≤ α     | 在线检测系统错误率是否超过 α  |

| 主要指标 | 累积错误率         | E-wealth trace   |

| 维度    | Split CP           | E-value       |

### ~~P2：Selective Prediction 实验~~（✅ 已完成，2026-04-12）

**背景**：在 E-value 触达高财富（近 `1/α`）时，部署上可采用**拒答**作为检测后干预，形成 coverage–selective accuracy 折中。

**拒答规则（实现）**：对 Probe+E-value 仿真得到的 `wealth_trace`，处理第 i 个测试样本**之前**若 W_{i-1} \ge 1/\alpha（对 wealth 裁剪导致的数值下偏使用 `1e-6·cap` 容差），则该样本 **abstain**；否则输出答案并计入 selective 统计。因 outcome-aware 更新下 wealth 可升可降，拒答为**逐样本门控**，而非「首次触 cap 后永久拒答」。

**指标**：

- Coverage = 回答数 / 总样本数
- Selective accuracy = 回答子集中满足 F_1 \ge \gamma 的比例

**主实验复现**（γ=0.5，predictive betting，无 shift，与 E5 一致）：

```bash
python -m stage3.run_stage3 \
  --datasets hotpotqa,musique,2wiki \
  --gammas 0.5 --alphas 0.1,0.2 \
  --betting-strategy predictive --results-dir results
```

**结果摘要**（`results/stage3_evalue_{dataset}.json` → `per_gamma["0.5"].per_alpha["0.1"|"0.2"].selective_prediction_abstain`）：

| 数据集      | α    | Coverage | Selective acc.（F1≥γ | 回答） | 拒答数 |
| -------- | ---- | -------- | ------------------------- | --- |
| HotpotQA | 0.10 | 0.625    | 0.547                     | 375 |
| HotpotQA | 0.20 | 0.720    | 0.556                     | 280 |
| MuSiQue  | 0.10 | 0.216    | 0.156                     | 327 |
| MuSiQue  | 0.20 | 0.225    | 0.149                     | 323 |
| 2Wiki    | 0.10 | 0.440    | 0.380                     | 560 |
| 2Wiki    | 0.20 | 0.489    | 0.376                     | 511 |

**产出**：每条 `per_alpha` 含 `wealth_trace`、`selective_prediction_abstain` 与 C–A 曲线 `results/stage3_selective_ca_{dataset}_g0_5_a*.png`；`docs/stage3_report_{dataset}.md` 含对应摘要行。

**解读**：HotpotQA 全量回答子集中 F_1 \ge \gamma 比例约为 1-\text{errorrate} \approx 0.56；在 α=0.1/0.2 的拒答规则下 selective accuracy 约为 0.55，与全量接近略低，说明当前门控主要在 **coverage–效用** 上折中而非显著提纯回答集。MuSiQue 因 wealth 更频繁处于高位，覆盖率显著更低（~0.22），可作为小样本高错误率 stress case。2Wiki 介于两者之间（coverage ~0.44–0.49）。
